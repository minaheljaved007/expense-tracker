# 💰 Expense Tracker

A lightweight, interactive expense-tracking web application built with **Python** and **Streamlit**.

The project focuses on clean separation between application logic and the user interface, input validation, expense accumulation, transaction management, and automated testing.

> 🎯 Built as a learning project to practice Python application architecture, state management, validation, testing, and web deployment.

---

## ✨ Features

- 💵 **Add expenses** with amount, category, and optional notes
- 📊 **Live running total** of all expenses
- 🧾 **Transaction history** showing recorded expenses
- 🗂️ **Category breakdown** of spending
- 📈 **Average expense** calculation
- 🗑️ **Delete individual expenses**
- 🧹 **Clear all expenses**
- ✅ **Input validation**
  - Rejects empty values
  - Rejects non-numeric amounts
  - Rejects zero and negative amounts
  - Handles commas and whitespace
- 🧪 **17 automated tests** covering the core expense-tracking logic
- 🔄 **Serialization support** using `to_dict()` and `from_dict()`
- 🌐 **Streamlit web interface**
- 📱 Simple and responsive browser-based UI
